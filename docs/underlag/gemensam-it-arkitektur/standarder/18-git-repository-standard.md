# Teknisk standard: Git och repository

## Syfte
Standardisera versionshantering av källkod och pipeline-definitioner.

## Typ
Teknikstandard

## Relaterad förmåga
- Programvaruutveckling och leverans

## Standard
- Git används för versionshantering.
- Huvudgren ska skyddas med definierade policies.
- Kodgranskning ska användas på nivå som motsvarar risk och förändring.
- Release/taggning ska ske enligt beslutad versionsmodell.
- Pipeline-as-Code ska versionshanteras.

## Avgränsning
Exakt branchstrategi kan variera mellan produktteam.
