# Teknisk standard: Developer tooling

## Syfte
Definiera godkända utvecklarverktyg utan att onödigt styra applikationsarkitekturen.

## Typ
Produktstandard

## Identifierad realisering
- IntelliJ IDEA för Java och relaterad utveckling

## Relaterad förmåga
- Programvaruutveckling och leverans

## Princip
IDE-val ska stödja produktivitet, support och säkerhet men får inte i sig styra systemarkitektur.

## Livscykel
Exakta versioner och licensnivåer hanteras separat.
