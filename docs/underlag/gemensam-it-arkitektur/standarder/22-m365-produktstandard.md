# Teknisk standard: Microsoft 365

## Syfte
Definiera Microsoft 365 som standardiserad produktfamilj för generell arbetsplats, samarbete och produktivitet.

## Typ
Produktstandard

## Relaterad förmåga
- Arbetsplats, samarbete och produktivitet

## Omfattning
Kan omfatta:
- Microsoft 365 Apps / Office
- Teams
- SharePoint
- OneDrive
- Exchange
- godkända AI-funktioner

## Princip
Respektive komponent ska användas utifrån sitt faktiska behov och inte automatiskt som plattform för verksamhetskritiska system.

## Livscykel
Tenantkonfiguration, licensnivåer och aktiverade funktioner dokumenteras separat.
