# Teknisk standard: Relationella databaser

## Syfte
Definiera vilka produktfamiljer som är godkända realiseringar av relationell databastjänst.

## Typ
Produktstandard

## Relaterad förmåga
- Data- och informationshantering

## Godkända/identifierade realiseringar
- Oracle Database
- Microsoft SQL Server

## Princip
Utvecklingsområdet ska i första hand konsumera Relationell databastjänst och inte kräva produkt om behovet kan uppfyllas av flera realiseringar.

## Valfaktorer
- workload
- funktionella krav
- tillgänglighet
- integrationsbehov
- kompetens
- kostnad
- licens
- livscykel

## Livscykel
Exakta produktversioner ska ligga i separat versions-/supportmatris.
