# Teknisk standard: Java Application Runtime

## Syfte
Definiera produktrealisering för förvaltad Java/Jakarta EE-runtime.

## Typ
Produktstandard

## Identifierad realisering
- JBoss EAP

## Relaterad förmåga
- Applikationsexekvering och runtime

## Princip
JBoss EAP används när applikationen behöver funktioner och supportmodell som motiverar applikationsservern.

## Avgränsning
Nya lösningar bör undvika onödigt beroende av produktspecifika funktioner.

## Livscykel
Exakta JBoss EAP- och Java-versioner hålls i separat supportmatris.
