# Teknisk standard: Objektlagring

## Syfte
Beskriva standardiserad realisering av objektlagring.

## Typ
Produkt-/realiseringstandard

## Relaterad förmåga
- Data- och informationshantering

## Identifierad realisering
Ceph kan användas som tekniskt byggblock för objekt-, block- eller fillagring där plattformstjänsten använder det.

## Princip
Konsumenter ska i första hand förhålla sig till Object Storage Service, inte till Cephs interna arkitektur eller produktkonfiguration.

## Livscykel
Exakt Ceph-version och klusterkonfiguration hålls separat.
