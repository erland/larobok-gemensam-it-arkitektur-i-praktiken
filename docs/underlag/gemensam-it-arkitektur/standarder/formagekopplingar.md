# Förmågor och konsoliderade standarder

| Förmåga | Primärt relaterade standarder |
|---|---|
| Interaktion, presentation och kanaler | Web frontend |
| Process, workflow och ärendehantering | API/Messaging vid integration; framtida BPMN-profil kan tillkomma |
| Regler och beslut | framtida DMN-profil kan tillkomma |
| Data- och informationshantering | Java persistence; Relationella databaser; Objektlagring |
| Analys, sökning och AI | Sökplattform; BI och rapportering |
| Integration och kommunikation | API; Messaging och events; Nätverkskommunikation; SGSI/SHS |
| Identitet och tillit | Identitetsprotokoll; Service identity; Secrets |
| Applikationsexekvering och runtime | Container; OpenShift; JBoss EAP; RHEL |
| Driftbarhet och motståndskraft | Observability; Backup och återställning |
| Programvaruutveckling och leverans | Jenkins; IntelliJ; Git; Release/version |
| Arbetsplats, samarbete och produktivitet | Microsoft 365; Power Platform governance |

Tabellen visar primär relation. Flera standarder är tvärgående.
