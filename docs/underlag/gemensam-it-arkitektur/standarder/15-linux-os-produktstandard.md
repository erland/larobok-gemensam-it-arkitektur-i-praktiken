# Teknisk standard: Linux serveroperativsystem

## Syfte
Definiera standardiserad Linux-produktfamilj för server- och runtimebehov.

## Typ
Produktstandard

## Identifierad realisering
- Red Hat Enterprise Linux (RHEL)

## Relaterad förmåga
- Applikationsexekvering och runtime

## Princip
RHEL är ett tekniskt byggblock inom VM-, runtime- och middlewareerbjudanden och ska normalt inte exponeras som eget verksamhetskrav.

## Livscykel
Godkända major/minor-versioner hålls separat.
