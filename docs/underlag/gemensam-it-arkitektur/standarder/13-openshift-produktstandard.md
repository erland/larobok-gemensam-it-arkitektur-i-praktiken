# Teknisk standard: Containerplattform

## Syfte
Definiera produktrealisering av Container Application Platform.

## Typ
Produktstandard

## Identifierad realisering
- OpenShift

## Relaterad förmåga
- Applikationsexekvering och runtime

## Princip
OpenShift är plattformsrealisering, inte ett krav som alla applikationer måste uppfylla.

## Avgränsning
Workloads som kräver annan runtime kan använda andra godkända erbjudanden.

## Livscykel
OpenShift-versioner och uppgraderingsfönster hanteras i separat plattforms-/supportdokumentation.
