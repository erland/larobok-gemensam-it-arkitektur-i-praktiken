# Teknisk standard: Web frontend

## Syfte
Definiera gemensam teknisk bas för större egenutvecklade webbaserade klienter.

## Typ
Teknikstandard

## Relaterade förmågor
- Interaktion, presentation och kanaler
- Programvaruutveckling och leverans

## Standard
- TypeScript bör användas som primärt språk för större webklienter.
- Angular är rekommenderad huvudrealisering när ett större SPA-ramverk behövs.
- Semantisk HTML och etablerade webbstandarder ska användas.
- Gemensamt Design System ska användas när dess komponenter möter behovet.

## Avgränsning
Standarden innebär inte att Angular ska användas för varje webbgränssnitt. Enklare eller serverrenderade lösningar kan vara lämpligare.

## Livscykel
Exakt Angular-/TypeScript-version hålls i separat versionslista och ska inte låsas i detta dokument.
