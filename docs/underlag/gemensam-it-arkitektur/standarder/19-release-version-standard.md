# Teknisk standard: Release- och versionsidentifiering

## Syfte
Skapa en entydig och automatiserbar källa för programvaruversion.

## Typ
Teknikstandard

## Relaterad förmåga
- Programvaruutveckling och leverans

## Standard
- Releaseversion ska så långt som möjligt härledas från Git-tag/release eller annan beslutad central versionskälla.
- Samma versionsnummer ska inte behöva underhållas manuellt i flera filer.
- Deploybar artefakt ska kunna kopplas till commit och releaseidentifierare.

## Versionsmodell
Semantic Versioning kan användas där det passar, men organisationen kan besluta annan modell för vissa produktkategorier.
