# Förmågor och konsoliderade lösningsmönster

Denna fil visar vilka konsoliderade lösningsmönster som främst relaterar till respektive förmåga.

| Förmåga | Primärt relaterade mönster |
|---|---|
| Interaktion, presentation och kanaler | Backend for Frontend |
| Process, workflow och ärendehantering | Human workflow |
| Regler och beslut | Externaliserade verksamhetsregler |
| Data- och informationshantering | System of record och härledda kopior; Cache-aside |
| Analys, sökning och AI | RAG; AI med mänsklig kontroll |
| Integration och kommunikation | Asynkron meddelandekommunikation; Publicera/prenumerera |
| Identitet och tillit | Tjänsteidentitet |
| Applikationsexekvering och runtime | Containeriserad stateless tjänst |
| Driftbarhet och motståndskraft | Observability för distribuerade tjänster; Backup och verifierad återställning |
| Programvaruutveckling och leverans | Build once, promote many |
| Arbetsplats, samarbete och produktivitet | Kontrollerad samarbetsyta |

Mönstren är tvärgående. Tabellen visar endast primär relation och ska inte tolkas som exklusivt ägarskap.
