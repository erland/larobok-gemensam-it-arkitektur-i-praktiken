# Plattform/tjänsteerbjudande: Java Application Runtime

## Syfte
Tillhandahålla förvaltad runtime för Java/Jakarta EE-applikationer.

## Primär förmåga
- Applikationsexekvering och runtime

## Möjlig realisering
- JBoss EAP

## Typiska behov
- applikationer med behov av Java/Jakarta EE runtime
- central support och patchning

## Begränsningar
Nya lösningar bör inte använda applikationsserverspecifika funktioner utan tydlig nytta.
