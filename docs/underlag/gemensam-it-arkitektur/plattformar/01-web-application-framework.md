# Plattform/tjänsteerbjudande: Web Application Framework

## Syfte
Ge utvecklingsteam ett gemensamt stöd för att bygga större webbaserade klientapplikationer med standardiserad struktur, komponenter och integration mot myndighetens gemensamma tjänster.

## Primär förmåga
- Interaktion, presentation och kanaler

## Sekundära förmågor
- Programvaruutveckling och leverans
- Identitet och tillit
- Driftbarhet och motståndskraft

## Typiska behov
- större interna eller externa webbgränssnitt
- standardiserad frontendstruktur
- gemensam autentisering
- återanvändbara komponenter
- tillgänglighet och testbarhet

## Erbjuden kvalitetsprofil
- definierad support- och livscykelmodell
- gemensamma projektmallar
- stöd för säkerhets- och kvalitetskontroller
- kompatibilitet med myndighetens design system

## Konsumentansvar
- verksamhetsspecifik UX och funktionalitet
- testning av den egna lösningen
- hantering av tillgänglighetskrav
- beroendeuppgraderingar inom stödd policy

## Plattformsansvar
- rekommenderad teknisk bas
- projektmallar och riktlinjer
- livscykel och kompatibilitet
- dokumentation

## Möjlig realisering
- Angular som nuvarande eller möjlig standardiserad realisering

## Begränsningar
Tjänsten är inte motiverad för varje enkelt gränssnitt. Serverrenderade eller enklare lösningar kan vara lämpligare.

## Livscykel
Teknikvalet ska kunna bytas utan att förmågan eller tjänstens syfte förändras.
