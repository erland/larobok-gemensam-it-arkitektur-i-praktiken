# Plattform/tjänsteerbjudande: Virtual Machine Runtime

## Syfte
Tillhandahålla virtuell maskin för workloads som kräver OS-nära installation, särskild middleware eller leverantörsstöd.

## Primär förmåga
- Applikationsexekvering och runtime

## Möjliga realiseringar
- RHEL-baserad Linuxmiljö
- andra godkända OS-profiler

## Typiska behov
- legacy
- COTS
- särskilda native dependencies

## Begränsningar
VM bör inte väljas enbart av vana om enklare förvaltad runtime uppfyller behovet.
