# Plattform/tjänsteerbjudande: Data Integration / ETL

## Syfte
Tillhandahålla kontrollerad dataförflyttning och transformation för batch- och dataorienterade integrationsbehov.

## Primär förmåga
- Integration och kommunikation

## Sekundär förmåga
- Data- och informationshantering

## Typiska behov
- batchöverföring
- dataextraktion
- transformation
- laddning till analyslager

## Möjlig realisering
- Microsoft SSIS

## Begränsningar
ETL-plattformen är inte förstahandsval för realtids-API:er eller eventdriven integration.
