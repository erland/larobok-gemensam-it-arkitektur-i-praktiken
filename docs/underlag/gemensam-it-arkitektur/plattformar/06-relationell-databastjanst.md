# Plattform/tjänsteerbjudande: Relationell databastjänst

## Syfte
Tillhandahålla förvaltad relationell databas för strukturerad verksamhetsdata med behov av transaktioner, konsistens och relationsfrågor.

## Primär förmåga
- Data- och informationshantering

## Sekundära förmågor
- Driftbarhet och motståndskraft
- Identitet och tillit

## Typiska behov
- transaktionell verksamhetsdata
- relationer mellan data
- stark konsistens
- strukturerade frågor

## Erbjuden kvalitetsprofil
Kan erbjudas i flera profiler för tillgänglighet, kapacitet, backup och restore.

## Konsumentansvar
- datamodell
- schema
- migrationsstrategi
- query- och indexdesign
- informationsklassning

## Plattformsansvar
- databasinstans
- patchning
- backup/restore enligt vald profil
- teknisk HA
- monitorering

## Möjliga realiseringar
- Oracle Database
- Microsoft SQL Server

## Begränsningar
Databastjänsten är inte en generell integrationsyta mellan oberoende system.
