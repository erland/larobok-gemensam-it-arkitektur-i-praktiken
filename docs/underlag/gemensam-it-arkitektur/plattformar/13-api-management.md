# Plattform/tjänsteerbjudande: API Management

## Syfte
Tillhandahålla gemensam exponering, skydd, publicering och förvaltning av API:er.

## Primär förmåga
- Integration och kommunikation

## Sekundära förmågor
- Identitet och tillit
- Driftbarhet och motståndskraft

## Typiska behov
- externa och interna API:er
- autentisering och policyer
- throttling
- API-livscykel
- utvecklarportal eller katalog

## Konsumentansvar
- API-kontrakt och semantik
- versionsstrategi
- verksamhetsmässigt ansvar

## Plattformsansvar
- gatewayfunktion
- policy enforcement
- teknisk exponering
- analytics och loggning

## Begränsningar
API management ersätter inte domän- eller integrationsdesign.
