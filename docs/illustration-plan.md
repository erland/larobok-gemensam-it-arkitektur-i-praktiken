- Metamodell: behov → kvalitet → förmåga → mönster/plattform → standard/byggblock → produkt.
- Förhållandet mellan verksamhetsförmåga, gemensam IT-förmåga och plattformstjänst.
- Från verksamhetskonsekvens till kvalitetskrav och verifiering.
- Referensarkitektur kontra lösningsarkitektur.

Arkitekturdiagram ska utformas som informationsbärande figurer och registreras här innan de skapas.
